# RepoLadder

Understand the codebase your AI just wrote, in minutes.

Run one command on your TypeScript or JavaScript repo and get a diagram you can click through. Every box and arrow comes from the code.

## Install

In Claude Code:

```
/plugin marketplace add repoladder/repoladder
/plugin install repoladder@repoladder
```

Then open your repo and run `/map`. You need Node.js 20 or newer.

## See one

Open a live diagram of [Excalidraw](https://repoladder.com/demo/excalidraw/). No install needed.
