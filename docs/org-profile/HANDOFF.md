# Org profile handoff

The profile text lives in `README.md` next to this file. This file is not published.

After the public cut:

1. Create the public repo `repoladder/.github`.
2. Copy `docs/org-profile/README.md` to `profile/README.md` in it. Nothing else is needed.
3. Pin `repoladder/repoladder` on the org page.
4. Upload the 500x500 org avatar from the brand exports (`org-avatar.png`) in the org settings.
5. Enable Discussions on `repoladder/repoladder` (the profile links to it).
6. Open the org page and click every link. The repo and Discussions links 404 until the cut.
