# Add a map badge

A small badge for your README that links to a RepoLadder map. It is a static image from shields.io, so it needs no account and sends nothing to RepoLadder.

Paste this at the top of your README, in your badge row:

```markdown
[![RepoLadder map](https://img.shields.io/badge/RepoLadder-map-12805F)](https://repoladder.com/browse)
```

It renders as a green "RepoLadder | map" badge.

The link goes to RepoLadder's hosted maps. When your own map has an address (a hosted map page, or the link to the diagram you published), put that address in the parentheses instead.

For an example of what a hosted map looks like, open [the Excalidraw map](https://repoladder.com/demo/excalidraw/).
